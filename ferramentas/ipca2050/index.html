                    Mês a mês · em R$

                    • Rendimento: o que o fundo paga no dia 15 sobre as cotas que você tem.
                    • Cotas (rendimento): quantas cotas inteiras o rendimento sozinho compra, somado à sobra do mês anterior.
                    • Cotas (rend. + aporte): quantas cotas inteiras rendimento, aporte e sobra compram juntos. É o que entra na carteira.
                    • Sobra: o troco que não completa uma cota; fica guardado (sem render) e entra na compra do mês seguinte.
                    • Clique no ano para abrir os meses. Na linha do ano, os valores são a soma do ano; cotas totais e patrimônio são os do fim do ano.

                    Configurar sincronização

                    O botão pede ao GitHub para ler o Notion agora, em vez de esperar a rodada das 22h. Para isso ele precisa de um token do GitHub que só pode disparar automações do repositório mourinha.

                    1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
                    2. Repository access: Only select repositories → mourinha.
                    3. Permissions → Repository → Actions: Read and write (nenhuma outra).
                    4. Gere, copie e cole aqui.

                    Ele fica guardado só neste aparelho, cifrado: só abre depois que a página é desbloqueada com a sua frase-senha.
